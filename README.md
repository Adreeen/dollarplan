# DollarPlan
DollarPlan is an AI-powered personal finance planner that helps users track income and expenses while providing budgeting suggestions using Google's Gemini AI.

## Features
- User authentication
- Income tracking
- Expense tracking
- Current balance calculation
- AI financial assistant
- Responsive dashboard

## Technologies
- Node.js
- Express
- EJS
- PostgreSQL
- Gemini API
- HTML/CSS/JavaScript
